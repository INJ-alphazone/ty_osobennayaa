Открытка для неё ♡
1) Открой index.html в браузере для проверки.
2) Для редактирования открой файл в VS Code.
3) Загрузить index.html в корень GitHub-репозитория и включить Settings → Pages → Deploy from a branch → main → /(root).
Фоновая фотография загружается из Unsplash, поэтому для неё нужен интернет.
